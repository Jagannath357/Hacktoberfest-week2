# SoloBooks AI — Product Roadmap

## Phase 1 (Current Release — Hacktoberfest Week 2)
- [x] Full local Next.js App Router application with dark/light themes.
- [x] Local SQLite persistence with minor-unit integer arithmetic.
- [x] Tesseract.js OCR and PDF text extraction.
- [x] Ollama integration with structured output extraction and model auto-discovery.
- [x] Human-in-the-loop review and correction interface.
- [x] Expense management, custom categories, and duplicate detection.
- [x] Invoice management with overdue tracking and local reminders.
- [x] Grounded AI Financial Assistant answering user questions from real records.
- [x] RFC 4180 CSV & JSON exports.
- [x] Privacy audit and workspace reset controls.
